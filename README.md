# Diskplain for Homebrew

The official Homebrew tap for [Diskplain](https://diskplain.limedot.io), a Mac disk space analyser that explains what each folder is.

```bash
brew install --cask pjotrs-osnovskis/diskplain/diskplain
```

The cask installs the same signed and notarized download as the website: Developer ID of LIMEDOT SIA, Team ID `YH67YBD663`. Diskplain then keeps itself up to date through its built-in updater.
